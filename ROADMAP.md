# 🗺️ AVDJ.ca Roadmap

**Mission**: To rebuild AVDJ.ca as the premier landing zone for the FlightDeck ecosystem, showcasing the "Future of Music" through a high-performance, pilot-themed web experience.

---

## 🛫 Phase 1: Reconnaissance & Architecture (Immediate)

*Goal: Establish the technical foundation and design language.*

- [ ] **Tech Stack Selection**
    - Evaluate using **Core CMS** (headless or direct) vs. a static generator (Astro/Vite).
    - *Constraint:* Must be extremely fast and SEO-friendly.
- [ ] **Design System ("The Cockpit")**
    - Define color palette (Dark mode, illuminated accents, HUD greens/ambers).
    - Select typography (Monospaced headers, readable sans-serif body).
    - Create reusable UI components (Buttons as switches, panels as instrument clusters).
- [ ] **Repository Setup**
    - Initialize Git structure.
    - Configure CI/CD pipelines (GitHub Actions -> GitHub Pages or Hosting).

## 🛠️ Phase 2: Assembly (Core Development)

*Goal: Build the main pages and structure.*

- [ ] **Hero Section**
    - Implement a high-impact "Take Flight" visual (3D element or interactive canvas).
    - Clear Value Proposition: "Professional Audio Tools for the Web."
- [ ] **Product Showcase (FlightDeck)**
    - Interactive carousel or grid showing available consoles (DN-1000F, MixKitPro).
    - Direct links to launch the web apps.
- [ ] **The Academy Bridge**
    - Prominent integration with `flightdeck.avdj.ca` for documentation and tutorials.
- [ ] **About / Mission**
    - The story of BrainAV and the pivot to creative technology.

## 📟 Phase 3: Avionics (Interactive Features)

*Goal: Demonstrate the technology directly on the marketing site.*

- [ ] **Live Audio Demo**
    - Embed a lightweight version of the `AudioEngine` to play a startup sound or background ambience.
- [ ] **Visualizer Integration**
    - Integrate the **Audio-Visualizer** repo as a background element.
- [ ] **Newsletter / Signal Corps**
    - Email capture for product updates (FlightDeck release notes).

## 🚀 Phase 4: Takeoff (Launch & Optimization)

*Goal: Go live and drive traffic.*

- [ ] **SEO Optimization**
    - Meta tags, Open Graph data (social sharing cards).
    - Sitemap generation.
- [ ] **Performance Tuning**
    - Asset compression (WebP images).
    - Lighthouse score auditing (Target: 95+ across the board).
- [ ] **Public Launch**
    - Announcement on social channels.
    - Update GitHub profile links.
